🔐 Encrypt Gist Tool

Enkripsi berlapis untuk Key + Gist URL — Hanya untuk penggunaan lokal

⚠️ JANGAN DEPLOY file ini. Gunakan hanya di browser lokal Anda.
Masukkan Key dan Gist URL, klik Encrypt, lalu paste hasilnya ke index.html.
Setelah itu jalankan build.ps1 untuk regenerate _worker.js.
📐 Skema Enkripsi:

Key (4 Layer):
PlainKey → XOR(salt) → Base64 → Reverse → Base64 → EncryptedKey

Gist URL (7 Layer):
PlainURL → XOR(key) → Base64 → Reverse → PosXOR(key) → Base64 → CharSub → Base64 → EncryptedURL
