PAKET PERBAIKAN short.raba.my.id v2 (2026-10-18)
=============================================
Menggantikan short-raba-fix-v1.zip. Isi v1 + 1 perubahan besar:
URL GIST DIHAPUS DARI HALAMAN (tidak bisa lagi diambil orang).

CARA UPLOAD (via web GitHub, seperti biasa):
1. Buka repo yg tersambung ke short.raba.my.id -> "Add file" -> "Upload files".
2. Upload SEMUA file dalam zip ini SEKALIGUS:
   - _worker.js            (timpa yg lama)
   - .assetsignore         (file BARU)
   - index.html            (timpa yg lama)
   - data/videos.json      (timpa yg lama)
   PENTING: data/videos.json harus tetap di dalam folder "data".
   Upload _worker.js, .assetsignore, index.html dulu di root repo,
   lalu buka folder "data" -> Upload files -> upload videos.json di sana.
3. Commit. Tunggu deploy Cloudflare selesai (cek menu Deployments).

WAJIB SETELAH DEPLOY — PASANG SECRET GIST (hanya kamu yg bisa):
Mulai v2, browser pengunjung TIDAK LAGI membaca Gist langsung.
 yg membaca Gist adalah WORKER, lewat secret ini:
1. Dashboard Cloudflare -> Workers & Pages -> project short.raba.my.id
   -> Settings -> Variables and Secrets -> Add.
2. Name: GIST_MASTER_URL | Type: Secret |
   Value: URL mentah Gist-mu (mis. https://gist.githubusercontent.com/...)
3. Save, lalu JANGAN LUPA: redeploy (Deployments -> deployment terbaru
   -> Retry deployment, atau push commit kosong) agar secret terbaca.
TANPA secret ini, /api/videos hanya menyajikan data/videos.json
(sparepart berisi 1 contoh) — web-mu tampil tapi daftar videonya contoh.

   dengan daftarmu, format SAMA seperti Gist:
